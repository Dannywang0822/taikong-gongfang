# 太空工坊

原创的浏览器火箭游戏。主线是建造、发射、入轨、再入开伞、着陆或失败。不打包成 APK。

这不是任何商业游戏的移植。物理规则参考了公开的静态分析结论，公式和程序都是自己写的。零件图是锁定的原创美术，运行时用 `assets/parts/` 里的 PNG。没有使用原作的图片、字体、音频或代码。

## 本地运行

需要静态文件服务器。直接双击 `index.html` 时，浏览器会拦截模块脚本。

```bash
python3 -m http.server 8080
```

打开 <http://localhost:8080> 。横屏保持现在的左右布局。手机竖放时自动改成上下布局：主菜单和世界列表把主要按钮放到底部，建造台在上、零件栏在下，飞行时油门和分离键贴着底部安全区。转回横屏不用刷新，飞行进度还在。

```bash
node --test tests/
```

## 怎么玩

1. **主菜单**。开始进入世界列表。继续会回到最近的世界。造火箭进入最近世界的建造台。
2. **世界**。可以打开已有世界，或起名新建。第一次会放进青芽一号和试飞场。
3. **建造**。点零件，再点亮起的圆点接上去。撤销、拆除、试飞在顶栏。没有燃料不能试飞。
4. **飞行**。油门在底部圆盘，左右转向，分离和开伞在右手。上面是近地点、远地点和时间加速。地图把镜头拉开，画出轨道。演示入轨会自己完成一次入轨、再入和开伞，碰到操纵就交回手控。
5. **着陆或失败**。伞要在足够低、速度合适时才张得开，贴地后会自己完全张开。撞得太狠，或在发射台上翻倒，会在大约 3 秒后进入失败界面。

键盘：建造时 Ctrl/Cmd+Z 撤销，Delete 拆除，Enter 试飞。飞行时 W/S 或上下键调油门，A/D 或左右键转向，空格分离，F 开伞，M 地图，`[` `]` 调整时间，+/- 缩放，Esc 菜单。触屏用画面上的按钮，双指缩放。

大气层里不能用解析档时间加速。发动机开着或伞还在张开时，时间保持一倍。

## 数值从哪来

青芽、银芽、恒星的半径、表面重力、大气和 SOI 倍率采用参考表里地球、月球、太阳的序列化值。推力、耗油、μ 重力、开普勒传播、大气密度、阻力权重、降落伞条件和碰撞分数也按那些规则实现。

零件的湿质量、干重比、推力和比冲是原创的，只把推重比调到飞得起来。姿态（反作用轮、喷管偏转、角阻尼、RCS 手感）和分离力、地表噪声、轨道半长轴同样是调出来的。RCS 的推力 1.5、比冲 120 用了参考序列化值。

存档在浏览器 `localStorage` 的 `taikong-gongfang-play-v2`，只存这个项目自己的 JSON。
