# 太空工坊

原创的浏览器太空飞行小样，个人研究。第一期（P0）能走完这条闭环：主菜单、世界列表、建造、飞行、失败或结束。

This is an original personal-research toy, not a port of any commercial game. Official Spaceflight Simulator is only a functional reference. No official images, fonts, audio, code, or other assets are included.

界面和零件用的是锁定的 v0.4 原创美术。锁定包里的图全部是自己画的，不是从官方应用里抽出的图片。运行时直接使用 `assets/parts/` 里的这些 PNG。五屏对照稿在 `assets/locked/ui/`，锁定说明在 `assets/locked/说明.md`。

## 本地运行

需要一个静态文件服务器。直接双击 `index.html` 时，浏览器会拦截模块脚本。

```bash
python3 -m http.server 8080
```

然后打开 <http://localhost:8080> 。手机或窄窗口会铺满宽度；宽屏上是居中的一列。

检查建造和飞行规则：

```bash
node --test tests/
```

## 怎么玩

1. **主菜单**。开始进入世界列表。继续会回到最近的世界；如果上次飞行还没结束，会接着飞。造火箭进入最近世界的建造台。教程和制作人员可以打开。模组、社区、商店、通知只显示「即将推出」，没有接任何未证实的协议。
2. **世界**。列表里可以打开已有世界。填写名称后点创建世界，会进入空的建造台。第一次打开时会放进两个示例：青芽一号（锁定稿那套火箭）和试飞场（一发小火箭）。
3. **建造**。顶栏是撤销、拆除、试飞。零件栏只有这 8 个自研件：指令舱、短储箱、长储箱、液体发动机、固体助推、分离器、降落伞、结构转接件。降落伞下面展示收起、展开、打开三态。整流罩等第一期不做的分类没有放进来。点零件，再点亮起的圆点把它接上。没有燃料时，底栏会写「这级还没有燃料，加上储箱再试飞。」
4. **飞行**。紧凑仪表：左上燃料条，右上菜单，底部圆形油门，速度和离地，速度方向箭头，以及左、右、分离、开伞。没有地图、时间加速或轨道转移。
5. **没有落地 / 已经落地 / 结束任务**。可以重试、结束这次飞行，或返回。

桌面键盘：建造时 Ctrl/Cmd+Z 撤销，Delete 拆除选中的零件，Enter 试飞。飞行时 A/D 或左右方向键转向，W/S 或上下方向键调油门，空格分离，F 开伞，Esc 打开菜单。

## 数值

零件质量、推力、比冲、这颗行星的半径和大气、开伞和落地的阈值，都写在 `js/data.js`。分析里没有可引用的官方数值，所以它们全部标成 **估计**，只为了让这一期能飞、能测。不要把这些数字当成官方数据。

吸附方式、燃料在分离前可以共用、分离先抛助推再断开最下面的分离器，也是自研规则。存档是浏览器 `localStorage` 里的本项目 JSON，不读取、不兼容其他游戏的存档。

## 这一期不做

地图、时间加速、轨道转移、商店、模组加载、账号和云存档。这些不在锁定的 v0.4 界面里。
