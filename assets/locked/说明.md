# 太空工坊 P0 原创界面稿 v0.4

相对 `../v0.3-p0/`（保留、未覆盖）。Danny 看过 v0.3 后决定不锁定，要求继续加强金属感。本版只升级质感，不回退功能。v0.2 同样保留。

## 功能范围（与 v0.3 相同）

1. 建造顶栏：撤销、拆除、试飞。
2. 零件栏排满第一期 8 个自研件：指令舱、短储箱、长储箱、液体发动机、固体助推、分离器、降落伞、结构转接件。整流罩等未列入 P0 的分类已收起。降落伞另给收起 / 展开 / 打开三态。
3. 飞行 HUD 保持紧凑仪表（底部圆形油门 + 速度 / 离地），不加回地图、加速、转移，保留菜单与左 / 右 / 分离 / 开伞。
4. 五屏：主菜单、世界、建造、飞行、失败/结束。世界列表与失败页无零件，界面控件与 v0.3 保持一致，不为改而改。

## 相对 v0.3 的质感

v0.3 已有箍环和体积，但整体偏软、偏手绘圆柱体。本版针对这一点：

- 边更硬、形状更利落，减少柔和空气感渐变（更快的明暗衰减、更窄的高光带、1px 硬抗锯齿）。
- 浅色金属上有清晰的轴向拉丝纹，箍环与喷管有环向拉丝，不只靠圆柱渐变加箍环。
- 箍环两侧增加凹陷接缝与唇边高光；边缘钻面/倒角更清楚。
- 喷管内壁加深，可见环向机加痕迹；喉部附近加热处理金属色（浅麦秆色与钢蓝），喷口附近略收烟灰。

全部像素为原创重绘。只把官方 Spaceflight Simulator 的公开商店截图当作视觉参考。稿件目录内不含任何原包图片、切图、字体、音频或提取物，未向任何人索要原包素材，未打开提取目录。第一期仍是 8 个自研件，名称用项目自己的叫法。

主菜单火箭、建造区火箭、飞行中火箭与拾取栏图标是同一套零件。单件与组装图在 `parts/`，复现脚本为同目录的 `render_parts.py`。
